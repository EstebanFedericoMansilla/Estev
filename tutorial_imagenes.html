Tutorial: Publicar Imágenes en Comentarios

Guía paso a paso para compartir imágenes en las webs

¿Qué aprenderás en este tutorial?

Te enseñaremos cómo publicar imágenes en la caja de comentarios de las Webs usando GitHub. Es más fácil de lo que parece, solo necesitas seguir estos simples pasos.

1

Crear un Repositorio en GitHub

Primero, necesitas crear un repositorio en GitHub donde subirás tus imágenes. Si ya tienes uno, puedes usarlo.

Luego, en el menú hamburguesa (las tres líneas horizontales), selecciona la opción "Issues".

2

Cargar tu Imagen

Una vez dentro de "Issues", haz clic en "New issue" y arrastra tu imagen al cuadro de texto.

GitHub subirá automáticamente la imagen y generará un código especial.

3

Copiar el Código

Dale al botón "Create issue" o simplemente copia el código que aparece cuando arrastras la imagen.

El código se verá así:

4

Pegar en los Comentarios

Ahora ve a la caja de comentarios de la Web donde quieres publicar la imagen y pega el código que copiaste.

¡Y listo! Tu imagen aparecerá en el comentario cuando lo publiques.

💡 Consejo importante:

No es necesario crear el issue. Puedes cancelar después de copiar el código. GitHub mantendrá la imagen alojada igualmente.
